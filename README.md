Algorithm was designed for a grouped linear network constructor (gLNC) which dependes on the following research backround. 
This research introduces grouped-pattern structures into both response and predictor variables, proposing a linear network construction method for high-dimensional grouped-pattern multivariate data. This method is established via converting linear network construction into a group-pattern-constrained mixed 0-1 integer optimization problem, developing regularization parameter selection via designing group test statistics for response groups, linking determination of regularization parameters to a test rejection rule, and adapting group lasso for predictor groups. 
The finite-sample simulations confirm that grouped-pattern integration significantly boosts network accuracy and illustrates that the proposed method performs over the existing approaches. Lung squamous cell carcinoma (the Cancer Genome Atlas data) is applied to genes (response layer) and copy number alterations (predictor layer) which reveals biologically meaningful associations with higher credibility than that of the existing methods.
